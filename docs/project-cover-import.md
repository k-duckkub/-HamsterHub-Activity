# วิธีใส่ภาพปกผลงานจริง

ตอนนี้ผลงานทุกชิ้นยังไม่มีภาพปก การ์ดจึงแสดงพื้นไล่สีของผลงานนั้นพร้อมไอคอนกิจกรรม
ซึ่ง**ตั้งใจให้อ่านออกว่ายังไม่มีภาพปก** ไม่ใช่ภาพเกมปลอม

## โฟลเดอร์และการตั้งชื่อ

วางไฟล์ที่:

```
public/assets/projects/<project-id>.<นามสกุล>
```

`project-id` คือ `id` ใน `data/projects.ts` เช่น `gx-1`, `rj-4`, `gj3-2`

## ขนาดที่แนะนำ

- อัตราส่วน **16:9**
- กว้าง **1280px** (ต่ำสุด 960px)
- `.webp` หรือ `.jpg` สำหรับภาพถ่าย/สกรีนช็อต, `.png` เมื่อจำเป็นต้องมีความโปร่งใส
- ไม่เกิน 400KB ต่อไฟล์

## เพิ่มลงในข้อมูล

ใน `data/projects.ts` เติมสองช่องนี้ให้ผลงานที่มีภาพแล้ว:

```ts
{
  id: 'gx-1',
  // ...
  coverImage: '/assets/projects/gx-1.webp',
  coverAlt: 'ภาพหน้าจอเกมที่เล่นได้ครั้งเดียว ตอนเริ่มด่านแรก',
}
```

ทั้งสองช่องเป็น optional ผลงานที่ยังไม่มีภาพก็ปล่อยว่างไว้ได้ตามเดิม

## สิ่งที่ต้องผ่านก่อน merge

1. `coverAlt` ต้องบรรยายภาพจริง ไม่ใช่ชื่อผลงานซ้ำ
2. ภาพต้องเป็นของเจ้าของผลงาน หรือได้รับอนุญาตแล้ว
3. อัตราส่วนต้องเป็น 16:9 เพื่อไม่ให้การ์ดกระโดดตอนโหลด
4. `npx tsc --noEmit` และ `npm run build` ต้องผ่าน
5. เปิดหน้าผลงานแล้วภาพต้องไม่ยืดหรือถูกครอปจนเสียความหมาย
