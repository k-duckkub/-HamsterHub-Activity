# วิธีเพิ่ม/แก้กิจกรรมจริง

ข้อมูลกิจกรรมบนเว็บมาจากไฟล์ CSV ของ CampHub โดยตรง **ไม่มีการพิมพ์ซ้ำด้วยมือ**

## เพิ่มกิจกรรมใหม่

1. วางไฟล์ CSV ไว้ที่ `data/source/activities/`
2. รัน

```bash
node scripts/import-activities.mjs
```

3. ตรวจว่า build ผ่าน แล้ว commit ทั้ง CSV และไฟล์ที่ถูกสร้าง

## หัวข้อที่สคริปต์อ่าน

| หัวข้อใน CSV | ใช้ที่ไหนบนเว็บ |
|---|---|
| ชื่อกิจกรรม | หัวข้อหน้า, ชื่อบนการ์ด, `<title>`, OG |
| คำโปรย 190 Text | ย่อหน้าแรกและ meta description |
| ประเภทกิจกรรม | ป้ายหมวดเหนือชื่อ (ใช้ตัวแรก) |
| วันที่เริ่มต้น / สิ้นสุด | ช่อง "วันที่จัด" |
| ข้อมูลเพิ่มเติมสำหรับวันที่สอน | ช่อง "เวลา/วันที่สอน" |
| วันที่รับสมัครวันสุดท้าย | ช่อง "รับสมัครถึง" และป้ายบนแถบกิจกรรมอื่น |
| จำนวนที่รับ | ช่อง "จำนวนที่รับ" |
| ค่าใช้จ่าย | ช่อง "ค่าใช้จ่าย" |
| คุณสมบัติผู้สมัคร | ช่อง "คุณสมบัติผู้สมัคร" |
| คุณสมบัติเพิ่มเติม | ช่อง "เพิ่มเติม" |
| ลิงค์ใบสมัคร | ปุ่ม "สมัครเข้าร่วม" (เติม `https://` ให้อัตโนมัติถ้าเขียนเป็นโดเมนเปล่า) |
| คำอธิบายกิจกรรม | เนื้อหาเต็ม คงบรรทัดและอีโมจิเดิมไว้ทั้งหมด |

**ช่องไหนว่างใน CSV จะไม่แสดงบนหน้าเว็บ** ไม่มีการเติมค่าแทน

## slug

สร้างจากชื่อกิจกรรม ถ้าชื่อยาวหรือเป็นภาษาไทย ให้กำหนดเองได้ที่ `SLUG_OVERRIDES`
ในหัวไฟล์ `scripts/import-activities.mjs` และถ้าสองรายการได้ slug เดียวกัน
สคริปต์จะเติมเลขต่อท้ายให้พร้อมเตือนบนหน้าจอ

## สิ่งที่ยังเป็นของชั่วคราว

- **ภาพกิจกรรม** ยังใช้ไอคอนจาก sprite sheet เดิม หมุนเวียนตามลำดับ
  เมื่อได้ภาพจริงให้ใส่ผ่านช่องภาพต่อกิจกรรม (ยังไม่มีในข้อมูล — รอไฟล์จริง)
- **ผลงานในแต่ละกิจกรรม** ยังเป็นตัวอย่าง แจกกระจายให้ทุกกิจกรรมมีของแสดง
  รอผลงานจริงจากผู้เข้าร่วม ดู `docs/project-cover-import.md`
