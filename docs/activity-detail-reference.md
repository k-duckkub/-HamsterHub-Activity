# แบบอ้างอิงหน้ารายละเอียดกิจกรรม (หน้า 2)

ผู้ใช้ส่งภาพนี้ไว้เป็นแบบตั้งต้นของหน้า `/activity/[slug]` — ยึดตามนี้เวลาปรับหน้านี้

## โครงหน้า

1. **แถบบนสุด** — ปุ่มย้อนกลับ (chevron ซ้าย) + คำว่า HamsterHub, ขวาสุดมีปุ่มแชร์กับบุ๊กมาร์ก
2. **แบนเนอร์เต็มความกว้าง** มุมโค้ง สัดส่วนกว้างกว่า 16:9 เล็กน้อย
3. **แถวปุ่มใต้แบนเนอร์** — หัวใจ + จำนวน, คอมเมนต์ + จำนวน, แชร์ (ชิดซ้าย) และบุ๊กมาร์ก (ชิดขวา)
4. **หมวดกิจกรรม** ตัวเล็กสีส้ม เหนือชื่อ
5. **ชื่อกิจกรรม** ตัวใหญ่ ตามด้วยคำโปรยหนึ่งบรรทัด
6. **ป้ายสถานะ** เช่น "ปิดรับสมัครแล้ว"
7. **แถวตัวเลข** คั่นด้วยเส้นตั้ง: วันที่ / จำนวนคนต่อทีม / ค่าสมัคร / รางวัล
   โดยตัวเลขอยู่บรรทัดบน คำอธิบายตัวเล็กอยู่บรรทัดล่าง
8. **"เกี่ยวกับกิจกรรม"** — ย่อหน้าบรรยาย ตามด้วยรายการหัวข้อย่อยจุดสีส้ม
9. **แถบขวา** เป็นการ์ดพื้นเข้ม หัวข้อ "กิจกรรมอื่นที่น่าสนใจ" รายการละ (ภาพปก + ชื่อ + วันที่)
   ปิดท้ายด้วยลิงก์ "ดูทั้งหมด →" สีส้ม

## ข้อมูลที่ยังไม่มีจริง

ตัวเลขในภาพอ้างอิงบางส่วนไม่มีอยู่ในข้อมูล CampHub จริง จึงยังไม่แสดง
และจะไม่ใส่ตัวเลขสมมติลงไป: ยอดถูกใจ, จำนวนคอมเมนต์, จำนวนคนต่อทีม, เงินรางวัล, สถานะเปิด/ปิดรับสมัคร

ที่มีจริงและแสดงอยู่แล้ว: วันที่จัด, เวลา/วันที่สอน, รับสมัครถึง, จำนวนที่รับ, ค่าใช้จ่าย, คุณสมบัติผู้สมัคร
